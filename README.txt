FUTPAT বাংলা ই-কমার্স ওয়েবসাইট (Frontend Demo)

চালানোর নিয়ম:
1. ZIP ফাইল Extract করুন।
2. FUTPAT ফোল্ডারটি VS Code-এ Open করুন।
3. index.html ফাইলটি Live Server দিয়ে চালান (অথবা ব্রাউজারে খুলুন)।

অ্যাডমিন:
admin.html খুলে ক্যাটাগরি ও পণ্য যোগ/মুছুন, দাম পরিবর্তন করুন এবং অর্ডারের অবস্থা আপডেট করুন।

গুরুত্বপূর্ণ:
এই সংস্করণটি HTML/CSS/JavaScript ও Browser Local Storage দিয়ে তৈরি ডেমো।
ডেটা একই ব্রাউজার/ডিভাইসে থাকে। বাস্তব ব্যবসায় ব্যবহারের আগে Backend, Database,
নিরাপদ Admin Authentication, Image Upload এবং Payment Gateway যুক্ত করতে হবে।
বাংলা ফন্ট Hind Siliguri Google Fonts থেকে লোড হয়; ইন্টারনেট সংযোগ প্রয়োজন।
